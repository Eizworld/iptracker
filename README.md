# Eiz IP Tracker Pro Toolkit

A Termux-ready, professional IP Tracker tool with color UI, multiple IP scanning, domain lookup, and Google Maps links.

## Install

pkg install git
git clone https://github.com/yourname/eiz-iptracker-pro
cd eiz-iptracker-pro
bash install.sh

## Run
python iptracker.py

## Features
- Track any IP
- Track your own IP automatically
- Scan multiple IPs and save report
- Domain → IP resolution
- Colorful menu & ASCII banner
- Google Maps link for location
